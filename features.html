마이웍스 기본 기능

매일 여는 업무관리오늘 · 일 · 거래 · 돈 · 사람을 한곳에

어떤 일을 하든 똑같이 쓰는 기본 기능입니다. 베이직(무료)에서 대부분 쓸 수 있고, 견적 승인·청구·AI 쓰기처럼 표시한 기능은 프로에서 열립니다.

오늘일거래돈사람확인 링크알림·연결AI 접속데이터·보안

오늘

아침에 열면 결정할 것부터 보입니다

마이웍스의 첫 화면은 할 일 목록이 아니라 ‘오늘 결정할 것’입니다. 내가 손대지 않으면 멈춰 있는 일을 먼저 처리하게 합니다.

  • 오늘 브리핑 — 지연, 오늘 마감, 검토 대기, 결정할 것의 개수
  • 검수 요청 — 담당자가 결과물을 올리고 확인을 요청한 업무를 승인하거나 보완 요청
  • 견적 수정 요청 — 고객이 확인 링크에서 수정을 요청한 견적
  • 입금 기한이 지난 청구서 — 입금 확인 또는 청구 링크 다시 보내기
  • AI 제안 — 클로드가 올린 업무 추가·상태 변경·연락처 제안을 승인하거나 거절
  • 합류 요청 — 초대 링크로 들어온 팀원 승인

일

맡기고, 검수 요청을 받고, 승인으로 끝냅니다

프로젝트와 매장의 업무를 한 보드에서 대기 → 진행중 → 검토 → 완료로 관리합니다. ‘다 했어요?’를 묻지 않아도 됩니다.

  • 프로젝트 — 브랜드별 카드, 업무 목록, 목표, 메모, 링크, 의견, 예산
  • 매장 — 지점별 업무, 정기 점검, 매출·비용, 메모
  • 업무보드 — 프로젝트·매장 업무를 한 보드에서, 검수와 AI 표시 포함
  • 검수 흐름 — 담당자가 납품물 링크와 메모를 붙여 요청, 본인 업무는 본인이 승인할 수 없음
  • 반복 업무와 템플릿 — 매주·매월 자동 생성, 자주 쓰는 업무 묶음 저장
  • 플랜 — 일·주·월 계획과 체크리스트를 나만 보는 공간에서

거래

견적에서 입금까지 한 줄로 잇습니다

고객 → 견적 → 진행·납품 → 청구 → 입금 확인이 한 안건으로 이어집니다. 어느 단계에서 멈춘 거래인지 바로 보입니다.

  • 연락처 — 고객·거래처·외주를 이름·회사·구분·메모로 관리하고 검색
  • 견적 — 항목·수량·단가를 넣으면 공급가·부가세·합계 계산, 단가표에서 골라 넣기 (프로 · 아웃소싱)
  • 견적 승인 — 고객이 확인 링크에서 승인하면 안건이 ‘진행’으로, 승인된 견적은 수정 불가 (프로)
  • 납품 확인 — 결과물 확인 링크를 보내고 확인 또는 수정 요청을 받음 (베이직 포함)
  • 청구 — 부가세 10% 별도 / 3.3% 원천징수 / 없음 중 선택해 받을 금액 계산 (프로)
  • 입금 확인과 미수금 — 입금되면 안건이 완료되고 재무에 수입으로 기록

돈

매출과 비용이 한곳으로 모입니다

프로젝트 예산, 매장 매출·비용, 외주 입금, 판매 손익이 재무로 모입니다. 월말에 통장을 다시 계산하지 않아도 됩니다.

  • 재무 기록 — 수입·지출을 프로젝트·매장별로 기록
  • 이달 재무 — 홈에서 이번 달 수입·지출·손익 확인
  • 모듈 손익 보내기 — 공간 운영·판매의 월 손익을 버튼 하나로 재무에 기록
  • CSV 내보내기 — 세무사에게 보낼 자료를 엑셀로 열 수 있는 형식으로

사람

연락처를 가져오고, 사람마다 초대 링크로 부릅니다

구글·휴대폰에 있는 연락처를 한 번에 옮기고, 함께 일할 사람에게는 초대 링크를 보냅니다. 보이는 범위는 화면에서 숨기지 않고 서버가 애초에 보내지 않는 방식으로 지킵니다.

  • 연락처 가져오기 — 구글 연락처(CSV), 아이폰·안드로이드(vCard), 네이버·아웃룩·엑셀(CSV), 붙여넣기. 같은 이메일·휴대폰은 하나로 합침
  • 사람 초대 — 사람마다 다른 링크를 카카오톡·문자·메일로 보내고, 받은 사람이 아이디를 만들면 승인 없이 지정한 프로젝트에 바로 참여
  • 보낸 초대 — 열어 봤는지, 참여했는지 보이고 취소하거나 기한을 다시 열 수 있음
  • 팀 초대 코드 — 여러 사람에게 같은 주소를 보내고 관리자가 승인하는 방식도 그대로
  • 역할 5가지 — 관리자, 직원, 현장 근무자, 시설 담당, 협력사
  • 현장 근무자 — 오늘 청소·시설 신고·오늘 발송만 보이고 예약자 이름·연락처·금액은 전송되지 않음
  • 협력사 — 참여 프로젝트와 맡은 업무만 보이고 예산·매출·연락처는 전송되지 않음
  • 퇴사·계약 종료 — 비활성화하면 즉시 로그아웃, 만든 AI 토큰도 함께 회수

확인 링크

고객은 가입 없이 링크 하나로 승인합니다

견적서, 납품물, 청구서를 링크로 보냅니다. 받은 사람은 로그인 없이 내용을 보고 승인·확인·수정 요청만 할 수 있습니다.

  • 진행 상황 공유 — 프로젝트 진행률과 업무 목록을 읽기 전용 링크로 보여 주고, 몇 번 열어 봤는지 확인. 예산·메모·의견은 나가지 않음
  • 상대가 누른 결과는 내 ‘오늘 결정할 것’과 활동 기록에 바로 남음
  • 링크는 30일(견적은 정한 기간) 동안 유효하고, 새 링크를 만들면 이전 링크는 닫힘
  • 링크 페이지에는 고객 연락처, 내부 메모, 다른 업무 정보가 나가지 않음
  • 수정 요청이 오면 고친 뒤 같은 링크로 다시 승인받을 수 있음

알림·연결

알아야 할 일은 먼저 알려 주고, 고객에게는 바로 보냅니다

확인하러 들어가지 않아도 됩니다. 내가 움직여야 할 일이 생기면 알림함에 쌓이고, 견적서와 청구서는 만든 자리에서 고객 휴대폰으로 보냅니다.

  • 알림함 — 견적 승인·수정 요청, 납품 확인, 업무 배정, 검수 요청, 참여 요청이 사람마다 쌓임
  • 때 맞춘 알림 — 업무 마감 전날, 입금 기한·견적 유효기간 전날, 세금 일정 3일 전과 당일
  • 아침 요약 — 오늘 마감·지연·챙길 것을 하루 한 번. 없는 날은 보내지 않음
  • 알림 설정 — 받을 종류, 방해 금지 시간, 아침 요약 시각을 사람마다
  • 문자·알림톡 — 링크를 만든 창에서 바로 발송. 내 솔라피 계정을 연결해 쓰고 요금은 솔라피에 직접
  • 자동 안내 — 입금 기한 전·지남, 견적 회신 요청, 예약 전날 안내. 낮 시간에만 보내고 직전에 상태를 다시 확인
  • 빠른 입력·찾기 — 한 줄로 업무·지출·연락처를 넣고 이름으로 화면을 찾음 (Ctrl+K, 휴대폰은 ＋)
  • 홈 화면에 추가 — 휴대폰에서 앱처럼 열림. 앱을 닫아도 오는 푸시 알림은 준비 중

AI 접속

클로드가 내 데이터로 답하고, 변경은 제안으로 올립니다

개인 토큰으로 클로드를 커넥터(MCP)로 연결하면 “오늘 뭐 해야 해?”, “외주 미수금 얼마야?”에 내 워크스페이스 데이터로 답합니다.

  • 읽기 토큰 — 묻고 정리하는 용도 (베이직 1개)
  • 쓰기 토큰 — 업무 추가·상태 변경·메모·연락처·외주 안건을 ‘제안’으로 올림 (프로)
  • 제안 → 승인 — 홈에서 승인해야 반영, 자동 반영은 고른 종류만
  • AI가 만든 업무·연락처에는 AI 표시
  • 토큰은 만든 사람의 권한 범위 안에서만 읽고, 시간당 60회·하루 1,500회까지

데이터·보안

데이터는 이용자의 것입니다

워크스페이스끼리는 데이터가 완전히 분리됩니다. 운영자 화면에도 업무 내용은 보이지 않고 개수만 보입니다.

  • 전체 백업·복원 — 백업 파일 하나로 내려받고 다른 기기에서 복원
  • 비밀번호·AI 토큰은 복원할 수 없는 해시(PBKDF2)로만 저장
  • 비밀번호 10회 연속 오류 시 10분 잠금, 30일 미사용 로그인 자동 종료
  • 모든 통신은 HTTPS, 데이터는 Cloudflare 클라우드에 보관
  • 이용자 데이터를 AI 학습에 쓰지 않음

엑셀·카톡으로 할 때와 무엇이 달라지나

상황엑셀·카톡·메모장마이웍스
견적 승인카톡으로 “네, 진행해 주세요”. 어느 버전에 대한 답인지 남지 않는다확인 링크에서 승인. 승인한 견적과 시각이 기록되고 안건이 진행으로 바뀐다
일 맡기기단톡방에 지시하고 “다 했어요?”를 다시 묻는다담당자가 검수를 요청하면 홈에 올라오고, 승인하거나 보완을 요청한다
근무자와 공유예약 목록을 통째로 보낸다. 연락처와 금액도 함께 간다근무자 기기에는 오늘 할 일만 간다. 예약자 정보와 금액은 전송되지 않는다
미수금 확인월말에 통장과 청구 메일을 맞춰 본다입금 기한이 지난 청구서가 홈에 올라온다
월 손익시트를 여러 개 열어 다시 더한다매장·외주·판매 매출과 비용이 재무로 모인다

업무관리에 관한 글

업무관리 1인 사업자 업무관리, 엑셀·카톡·메모장에 흩어진 일을 한곳으로 모으는 법

혼자 사업하면 일이 엑셀, 카톡, 메모장, 통장 앱에 흩어집니다. 1인 사업자가 놓치는 일을 줄이는 업무관리 순서와 도구를 고르는 기준을 정리했습니다.

2026. 11. 16. · 읽는 시간 3분 업무관리 업무관리 엑셀, 언제 바꿔야 할까 — 엑셀이 한계에 다다랐다는 다섯 가지 신호

엑셀로 업무관리를 시작하는 것은 좋은 선택입니다. 다만 사람이 늘고 거래가 쌓이면 한계가 옵니다. 엑셀에서 업무관리 도구로 옮길 때를 알려 주는 신호와 옮기는 순서를 정리했습니다.

2026. 11. 16. · 읽는 시간 2분 업무관리 직원·아르바이트 업무 지시, 카톡 대신 체크리스트로 남기는 법

카톡으로 업무를 지시하면 빠르지만 기록이 흩어지고 확인이 어렵습니다. 근무자·아르바이트·외주 파트너에게 일을 맡기고 결과를 확인하는 방법을 체크리스트와 검수 중심으로 정리했습니다.
